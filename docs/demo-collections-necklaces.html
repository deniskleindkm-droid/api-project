Note for Dennis: Removed "Refine by Finish" per your request — "Discover by Stone" is the only filter now. Unlike Rings, Necklaces actually has real inventory in all four stone types (Moissanite, Pearl, Cubic Zirconia, Gemstones), so all four tiles show here. One thing to flag: today's material data gives each product exactly one label (e.g. a product is either "Moissanite" or "Gold," never both), so necklaces whose only label is a metal (not a stone) won't appear under any of these tiles — they still show in the default unfiltered view, just aren't reachable via a filter click. Splitting material detection into separate stone/metal fields (like Bracelets and Earrings have) would fix that if it matters later.
